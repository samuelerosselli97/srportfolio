PART 04

Rapid Spanning Tree

RAPID PVST+
HSRP-STP alignment: the root bridge of each VLAN coincides with the active HSRP router. This avoids suboptimal routing (traffic crossing the wrong switch).
RAPID PVST+ + PRIORITY + PORTFAST
! Enable Rapid PVST+ on all distribution and access switches:
(config)# spanning-tree mode rapid-pvst

! DSW-A1 — root for VLAN 10,99 | secondary for 20,40:
DSW-A1(config)# spanning-tree vlan 10,99 priority 0
DSW-A1(config)# spanning-tree vlan 20,40 priority 4096

! DSW-A2 — root for VLAN 20,40 | secondary for 10,99:
DSW-A2(config)# spanning-tree vlan 20,40 priority 0
DSW-A2(config)# spanning-tree vlan 10,99 priority 4096

! DSW-B1 — root for VLAN 10,99 | secondary for 20,30:
DSW-B1(config)# spanning-tree vlan 10,99 priority 0
DSW-B1(config)# spanning-tree vlan 20,30 priority 4096

! DSW-B2 — root for VLAN 20,30 | secondary for 10,99:
DSW-B2(config)# spanning-tree vlan 20,30 priority 0
DSW-B2(config)# spanning-tree vlan 10,99 priority 4096

! PortFast + BPDU Guard on ports facing end hosts:
(config)# interface f0/1
(config-if)# spanning-tree portfast
(config-if)# spanning-tree bpduguard enable

! Special case ASW-A1 F0/2 (trunk to WLC1):
(config-if)# spanning-tree portfast trunk
