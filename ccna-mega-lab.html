What I configured

Layer 2

802.1Q trunks with a dedicated native VLAN and DTP disabled, VTPv2, PAgP and LACP EtherChannels, Rapid PVST+ with root bridges aligned to HSRP, PortFast and BPDU Guard.

Layer 3

Routed EtherChannel between core switches, SVIs, HSRPv2 with 8 groups, single-area OSPF (router IDs, passive SVIs, point-to-point links), recursive and floating static routes, R1 as ASBR.

IP services

DHCP server with relay agents, DNS, NTP with MD5 authentication, SNMP, Syslog, FTP-based IOS upgrade, static NAT and pool-based PAT with ISP failover testing.

Security

SSHv2 with RSA 4096 restricted by ACL, extended ACL between offices, Port Security, DHCP Snooping, Dynamic ARP Inspection, hashed secrets (type 5 and type 9).

IPv6

Manual, EUI-64 and link-local addressing, IPv6 default routes including a floating route.

Wireless

WLC with a dynamic interface and a WPA2-PSK WLAN, lightweight APs in CAPWAP local mode, DHCP option 43 for cross-site AP discovery.
